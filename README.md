# Student-Grade-Manager
## Inspiration

I wanted to create a Python project that would be useful in a real-world situation while practicing the programming concepts I had learned. Since managing student grades involves storing, calculating, and organizing information, I decided to build a simple Student Grade Manager.

## What it does

The Student Grade Manager is a Python program that allows users to manage student grades through a simple menu system.

Users can:

* Add students and their grades
* Remove students
* View all students and their grades
* Calculate the average grade
* Find the student with the highest grade
* Save student information to a file so the data can be used again later

The program also uses error handling to prevent invalid inputs from crashing the program.

## How we built it

The project was built using **Python**.

Some of the main concepts I used include:

* Functions
* Lists and dictionaries
* File handling
* `try`/`except` error handling
* Loops and conditional statements
* User input
* Data persistence using a `students.txt` file

The program uses a menu system to allow the user to select different actions.

## Challenges we ran into

One of the main challenges was figuring out how to save student information to a file and load it again when the program starts.

Another challenge was handling invalid user input. For example, the program needed to continue running instead of crashing when a user entered something that wasn't a valid grade.

I also had to make sure that adding, removing, and updating information worked correctly with the saved data.

## Accomplishments that we're proud of

I am proud that I was able to build a complete working program that can store and manage information rather than just performing individual calculations.

I am also proud of implementing file persistence and error handling, which made the program more practical and reliable.

This project was one of my first larger Python projects and helped me become more comfortable writing programs with multiple functions and features.

## What we learned

Through this project, I learned more about organizing a Python program into separate functions and using files to store data.

I also learned how important error handling is when creating programs that interact with users.

Most importantly, I learned how to take an idea and turn it into a complete working application by breaking the problem into smaller features.
